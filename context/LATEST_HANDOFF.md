## What this session actually taught us (3 findings)
1. **A deferral's projected cost can be wrong in the cheap direction too.** S281 deferred the tolerance fix partly because it "flips an existing self-test assertion — a deliberate semantics change." It didn't. Requiring callers to *prove* the corroborator excludes the run under test keeps the old assertion true and unchanged; the change was strictly additive, 9 → 16 cases. The deferral was still *right* (it refused to hack a gate green under context pressure), but re-verify a deferral's premise before inheriting its cost estimate.
2. **Timing can be evidence.** e2e was GREEN when the tolerance fix shipped — a better trend value had landed and made the bug dormant, not fixed. Shipping the change *then* is what proves it isn't a gate hacked green. A latent flake is worth fixing precisely when nothing is on fire.
3. **A signal whose producer doesn't exist reads exactly like a healthy one.** That is the purest form of the CANON-031 lie, and it was sitting on the project's own primary health indicator. Generalised rule now recorded: **when a signal names a producer, assert the producer exists — an absent producer must degrade the signal, never silently preserve its last value.**
