**D-S309.3 -- A repairer is only as complete as its map, and silence reads as coverage.** The evidence graph models 17 nodes while the repo byte-checks more. `proof-aware-projects` and `cta-readiness` both drifted this session in exactly the way `resync-derived` exists to fix, and it could not help, because they are unmodeled — invisible to the repairer AND to `check-publish-cascade-coverage`. Deliberately deferred rather than bolted onto a pending push: expanding the graph changes what the cascade checker demands of every cron and needs its own verified pass.

**D-S309.4 -- A share card that renders correctly can still say the wrong thing.** The Director's Report shipped live pointing at the generic site image, and the first fix — reusing `renderDispatchCardSvg` — published "THE DESK · THE DISPATCH" and "No account required · double opt-in" over a performance review, with the headline clipped to "Three writers carried the week. **D-S309.5 -- A review is OF a period, so it must be measured over that period.** The Director's Report showed each writer's stats derived live from the whole corpus while the ranking and feedback stayed as authored. **D-S309.6 -- Alt text for a generated image is derived, never authored.** These panels are deterministic SVG: the register picks the picture, so any hand-written sentence about it is an unverified parallel claim. It drifted twice in one session — a discarded motif, and a motif the register ignores entirely — and every gate stayed green, because `check-og-images` verifies that a real raster of the right size exists and cannot compare words to pixels. **D-S309.7 -- Coverage debt is ratcheted, not guessed shut.** 51 generators run with `--check` in build:check; the evidence graph modeled 12. Adding the other 39 with inferred `sources` would have made the graph confidently wrong — resync-derived rebuilding in a wrong order, check-publish-cascade-coverage demanding the wrong things of every cron — which is the precise failure mode this family of tools exists to prevent. So the debt is made visible and monotonic: a baseline that may only decrease, and a new byte-checked generator must be modeled at the moment it is added, when whoever wrote it still knows its inputs. Only `proof-aware-projects` was modeled, with sources read out of the generator rather than assumed.

**D-S309.8 -- A change-detector's blind spot is permanent, not occasional.** `resync-derived` computes dirtiness from `git diff`, so it was blind to `founder-presence`, whose source `context/.session-lock` is untracked — and the lock is written at session start and cleared at closeout, so its output changes on exactly the boundary a rebase happens. The tool reported success three times while leaving it stale; only the independent pre-push coherence hook caught it. Nodes with untracked sources are now always rebuilt, and a self-test names `founder-presence` so rewiring it trips an assertion instead of going quiet. The general rule: fixing "which nodes depend on this" while leaving "how do we know a source moved" naive yields a tool that is confidently wrong on a fixed subset forever.

**D-S309.10 -- Editorial is exempt from studio-posture framing; self-description is not.** Founder call taken explicitly, superseding the open question left in D-S309.9. `check-studio-content-posture` guards how the STUDIO presents itself, so on `/news/` — journalism about other organisations — it was firing on the wrong subject: JUNO naming an AWS support engineer tripped "one person" and blocked the build. **D-S310.1 -- A statistic on a public page is computed, never asserted.** The story bar printed "The desk disagrees" from a heat threshold. **D-S310.2 -- Reader reactions are editorial signal with somewhere to go.** "Changed my mind / Already knew this / Show more receipts / Made me laugh" say something a newsroom can act on; a heart says nothing.
