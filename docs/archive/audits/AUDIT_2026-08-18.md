### 2. [OBS/P0] Synthetic probes that never touch the paths that actually failed

**Evidence (live code):**
- `scripts/probe-uptime.mjs:440` probes `/v/rum` with **`OPTIONS`**, asserting `status === 204`
  (`corsRumResponse`). The CORS preflight answers 204 **even while `POST /v/rum` returns 500** —
  which is precisely how the telemetry outage stayed invisible long enough that
  `data/news-desk-engagement-history.ndjson` never existed at all.
- `/login` does not appear in the probe set at all. Production sign-in returned HTTP 500 and was
  found incidentally during a deploy, because no trust surface exercised the auth entry point.

**The class:** a probe that proves *a route is wired* is not a probe that proves *the route works*.
Reachability ≠ correct status on the real method.

**Action:** add probes that exercise the real methods and assert the **expected status**, not mere
reachability — `POST /v/rum` (accepted ingest) and `GET /login` (auth entry point renders). A named
degradation (503 `auth_store_unavailable`) must be distinguishable from a crash (500/1101).

### 3. [GATE/P0] `check-writeback-currency` reports green on an unmeasurable window

**Evidence — reproduced live this session, in both directions:**
- Before `git pull`: reported **write-back debt** against anchor `84cc4808`.
- After pulling 31 CI-chore commits: *"no `context/SELF_IMPROVEMENT_LOOP.md` commit in the inspected
  range — cannot measure write-back currency"* — and **exit 0**.

**Root cause (live code):**
- `readCommits(root, opts.limit || 60)` — a **fixed 60-commit window**.
- `evaluateWriteBackCurrency`: `anchorIdx === -1` → returns `{ ok: true, unmeasured: true }`.
- CLI: `process.exit(result.ok ? 0 : 1)` — the `unmeasured` flag is computed, carried in the JSON,
  and then **discarded by the exit path**.

So once ~60 commits of `[skip ci]` beacon churn accumulate between closeouts, the SIL anchor falls
out of the window and the arc's own F7 cut-off detector goes permanently, silently green. This is
the exact false-negative F7 exists to prevent, living inside F7 itself.

**Action:** `unmeasured` must not exit 0 as a pass. Widen the search until the anchor is found
(or search by path rather than a fixed count), and give "cannot measure" a distinct non-pass exit
so it reads as *degraded*, never as *clean*.
