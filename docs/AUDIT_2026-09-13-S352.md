## 1 · [CI/P1] The Desk publisher stages `sitemap.xml` but never rebuilds it

**Found by measurement.** `generate-sitemap.mjs --check` was red on a freshly pulled
`origin/main`. Regenerating added exactly one route:
`/news/2026-09-12/anthropic-says-it-blocked-potential-ai-bioweapon-misuse/`, published
by `83796e1ad feat(desk): publish the midday edition [skip ci]`.

**Root cause:** `.github/workflows/news-publish.yml` lists `sitemap.xml` in its `git add`,
but its cascade step never runs `generate-sitemap.mjs`. Every new story reached
production missing from the sitemap until a human session happened to rebuild it.

**Why no gate saw it:** `check-publish-cascade-coverage` printed "all publish cascades
closed". The evidence graph had no `sitemap` node, so there was no edge for the gate to
check. This is the structural half of the S351 `[CI/P1]` row, and it covers the sitemap
only, not every artifact.

**Do:** add `sitemap <- news/` to `config/evidence-graph.json` with `publishCascade: true`.
Run the gate *before* fixing any workflow as a negative control, then close every
publisher it names and widen the self-test fixture with mutation cases.

## 2 · [OBS/P1] The write-back check counts a regeneration-only commit as session work

**Found by measurement.** At `/start`, `check-writeback-currency --explain` reported
WRITE-BACK DEBT for `c29a1b0f chore(release): regenerate derived artifacts after second
publisher rebase`. Every one of its 35 files is generator output. It was counted because
`brand/assets.json`, `data/stats-surface.json`, `feed/forge-ledger.*`, `stats.json`,
`assets/shell-manifest.json` and `.cache/*` match none of the hand-written path patterns.

**Why it matters:** a probe that raises false debt gets ignored, and an ignored probe
catches nothing. It is the S320 over-report again, arriving through a different subject line.

**Do:** read the generated set from the evidence graph (non-HTML, non-shared outputs
plus `alsoStage`) instead of growing the regex list, and add `.cache/`. Tests must cover
both directions: the real `c29a1b0f` file list is churn, the same list without a graph
counts as debt, and a homepage edit stays substantive.
