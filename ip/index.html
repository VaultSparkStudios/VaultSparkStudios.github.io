Built in the Forge. Protected in the Vault.

This is the public doorway to VaultSpark Studios intellectual property posture: what we create, what we protect, and where third-party technology fits. Public visibility is not an implied license—VaultSpark products, worlds, brands, assets, and studio systems remain proprietary unless an explicit written grant says otherwise.

What the Vault Protects

Website, games, projects, lore, and studio systems Proprietary

All VaultSpark Studios games, software, pipelines, Studio OS materials, creative assets, names, logos, taglines, worldbuilding, characters, and related commercial code are proprietary to VaultSpark Studios LLC unless a specific repository or file says otherwise.

Public GitHub visibility Not an implied license

Code being visible on GitHub or deployed on the public web does not grant permission to reuse, copy, modify, train on, resell, or redistribute VaultSpark Studios property. Any permitted third-party use must be covered by an explicit written license from VaultSpark Studios LLC.

Brand and creative restrictions Reserved

VaultSpark marks, product names, logos, key art, characters, lore, screenshots, trailers, music, and studio presentation assets are reserved rights materials. They are not covered by any software-style reuse license.

Repository-specific exceptions Explicit only

If VaultSpark Studios ever releases a repository or file under a permissive license, that permission must be stated explicitly in that repository or file. Do not infer MIT or open-source rights from older site copy, public availability, or GitHub indexing.

Third-Party Attributions

VaultSpark Studios products and websites rely on third-party software, services, and frameworks. The list below is attribution, not a statement that VaultSpark-owned code is open-source.

Website & Frontend

  • Google Analytics (GA4) — analytics & usage measurement
  • Supabase — authentication, Postgres database, real-time subscriptions, Edge Functions (Apache 2.0 / MIT)
  • Sentry — error tracking & performance monitoring
  • ConvertKit (Kit) — email list & dispatch delivery
  • Web3Forms — serverless contact-form submission API
  • Stripe — subscription billing for VaultSparked & Eternal tiers
  • Cloudflare Turnstile — privacy-respecting bot challenge on sensitive forms

AI & Intelligence

  • Anthropic Claude API — powers Ask IGNIS, the automated Eternal Dispatch, and select studio-intelligence surfaces. SDK is Apache 2.0; Anthropic's terms govern model use.

Build & Development

  • Node.js — build & script runtime (MIT)
  • Playwright — end-to-end test framework (Apache 2.0)
  • Deno — Supabase Edge Function runtime (MIT)

This site ships as hand-authored HTML, vanilla JavaScript, and vanilla CSS — no React, no Vite, no TypeScript compilation. That is intentional: zero-build, zero-runtime-framework, maximum legibility.

Infrastructure & Hosting

  • GitHub Pages — static site hosting for the public website
  • GitHub Actions — CI/CD, propagation checks, secret scanning
  • Cloudflare — DNS, CDN, security headers, WAF, rate limiting
  • Cloudflare Workers — edge routing, security headers, and private-subdomain auth (Studio Hub)
  • Cloudflare Workers KV — rate-limit counters & short-lived intelligence cache
  • Hetzner — staging environment at website.staging.vaultsparkstudios.com

Client-Side Runtime

  • Service Worker / PWA — offline capability, asset pre-cache, install prompt
  • Simple Icons — SVG sprite source for social & brand iconography (CC0 1.0)

Usage Summary

Unless a specific VaultSpark repository or file includes an explicit license grant from VaultSpark Studios LLC, assume all VaultSpark-produced code and materials are proprietary and all rights are reserved.

For trademark, copyright, and permitted-use boundaries, see our Trademark & Copyright and Terms pages.

Questions about rights or permitted use? Contact founder@vaultsparkstudios.com.
