VaultSpark Studios  ·  Developers & agents

Every public feed,
in one place.

The studio publishes its own status, numbers and receipts as plain JSON (JavaScript Object Notation) files. Nothing here needs a key: fetch them, cite them, build on them. Each feed carries a generatedAt timestamp, so you can tell fresh from stale.

Start here

The files any crawler, assistant or integration should read first.

  • /agents.jsonagents.jsonMachine-readable manifest of the site: public endpoints, feeds, authenticated actions and the project catalog.
  • /.well-known/llms.txtllms.txtPlain-text index written for language models, pointing at a fact sheet for every project.
  • /llms-full.txtllms-full.txtThe long-form companion to llms.txt — the studio and its projects in one file.
  • /sitemap.xmlsitemap.xmlEvery indexable page with its last content date.
  • /robots.txtrobots.txtCrawler policy: search and answer agents allowed, training crawlers blocked.
  • /.well-known/entity-graph.jsonEntity graphThe studio, its projects and their relationships as linked data.
  • /feed.xmlRSS feedSite updates as an RSS (Really Simple Syndication) feed.
  • /api/news-desk-feed.jsonThe Desk JSON FeedNewsroom editions in JSON Feed format.

Public JSON feeds (27)

The same curated catalog agents.json advertises. Every feed is public, privacy-safe and stamped with the time it was generated.

  • Public Analytica statistics

    /stats.json

    Source-dated portfolio, audience, editorial, proof-freshness, and performance aggregates rendered at /evidence/#numbers.

  • Studio ecosystem analytics

    /api/ecosystem-stats.json

    Production-only audience estimates, edge traffic, project coverage, and measurement states used by /stats/ecosystem/.

  • Cloudflare analytics receipt

    /api/ecosystem-analytics.json

    Source-window-sampling provenance and per-project aggregates from Cloudflare Web Analytics and zone Traffic Analytics.

  • The Desk engagement receipt

    /api/news-desk-engagement.json

    Per-article visible-and-focused reading time with privacy floors, plus the live-presence measurement contract.

  • The Desk editorial freshness

    /api/news-desk-freshness.json

    Latest-edition observed-through date, evidence-backed cadence label, overdue state, and the automatic scheduled-publication policy.

  • The Desk automation receipt

    /api/newsroom-run.json

    Privacy-safe scheduled-run evidence, latest public edition, next expected UTC slot, and explicit abstention when CI has not observed a run.

  • The Desk reader-signal receipt

    /api/news-desk-reactions.json

    Per-article reader reactions and per-voice votes, suppressed below five signals, with declared reset semantics for cumulative edge counters.

  • Portfolio intelligence

    /api/public-intelligence.json

    Full project catalog with live VaultStatus (SPARKED/FORGE/VAULTED), mediums, and notes.

  • Studio status

    /api/public-status.json

    Nervous-system snapshot: repos online, sparked/forge/vaulted counts, last shipped session.

  • Live signal digest

    /api/nervous-system.json

    Aggregated live activity tiles (continuous integration, uptime, motion) rendered inside /studio-pulse/#signal-digest.

  • Shipping velocity

    /api/velocity-series.json

    24-week shipping cadence derived from git history (no private data).

  • Cite-ready facts

    /api/citation.json

    Authoritative, refresh-on-deploy facts about the studio for AI summarization.

  • Status provenance

    /api/status-proof.json

    Signed/derived provenance for the public status claims (anti-fabrication).

  • Trust-feed provenance

    /api/feed-publishers.json

    Every public trust feed mapped to its generator script, exact recovery command, scheduled workflow, and freshness ceilings — so an agent can verify (or recover) any stale studio signal.

  • Evidence dependency graph

    /api/evidence-graph.json

    Resolved relation view of every derived public artifact: which feed is built from which, the builder that produces it, and the exact command that verifies its bytes. Lets an agent reason about how any published number was produced.

  • Build verification receipt

    /api/build-check-diagnostics.json

    Integrity-bound receipt for the complete current build plan: plan fingerprint, executed/planned coverage, direct exit codes, timings, and zero command output.

  • Proof-surface verification receipt

    /api/proof-surface-diagnostics.json

    Integrity-bound blocking/advisory substep receipt with planned coverage, direct exit codes, timings, and owner/class failure attribution.

  • Edge route incident history

    /api/worker-route-history.json

    Append-only semantic route history with source-labelled onset bounds and self-validating recovery transitions. Records status codes and verdicts only — no response bodies or identifiers.

  • Production deploy parity

    /api/deploy-currency.json

    Probe-frozen production SHA age plus route-local fingerprinted-shell parity. Distinguishes a current artifact from stale or shell-drifted production without retaining response bodies.

  • Top questions

    /api/oracle-query-insights.json

    What humans + agents most ask the Oracle, with answer coverage.

  • Oracle prebaked answers

    /oracle/answers/index.json

    Deploy-time, source-backed Oracle answers for common studio, game, rank, and membership questions.

  • Deploy pointer

    /api/build-sha.json

    The exact commit SHA currently served in production.

  • Release proof

    /api/release-proof.json

    Source-derived staging parity, deploy pointer, canonical favicon, and automatic rollback readiness.

  • Identity migration receipt

    /api/identity-migration-receipt.json

    Privacy-safe Obelisk migration evidence: issuer/callback binding, staged Worker, runtime updates, role/revocation proof, rollback, and explicit honest-dark blockers.

  • Supabase authority receipt

    /api/supabase-control-plane.json

    Read-only, public-safe proof that distinguishes REST data administration from management API, SQL migration, and Edge Function deployment authority.

  • Membership pricing

    /api/membership-tiers.json

    Canonical tier facts: Free / VaultSparked ($4.99/mo) / VaultSparked Eternal ($29.99/mo), monthly only — enforced perks and themes.

  • Outcome-first intent map

    /api/intent-map.json

    Maps play, join, verify, invest, press, build, and news goals to resolvable routes, evidence freshness, action capability, fallback, and honest abstention.

Want to check these claims rather than read them? The Evidence page re-computes the deploy ledger in your browser. Questions or a feed you need: contact the studio.
