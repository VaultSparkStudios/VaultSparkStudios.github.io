Your first public read

Copy either command into a terminal. These examples only GET public files: they do not subscribe anyone, create an account or invoke a model.

Read the latest Desk feed

curl --fail --silent --show-error 'https://vaultsparkstudios.com/api/news-desk-feed.json'

JSON Feed returns items with article titles, URLs and publication dates. Follow each article URL for its full story and evidence.

Read the project catalog

curl --fail --silent --show-error 'https://vaultsparkstudios.com/api/public-intelligence.json'

Use the catalog's source timestamp and project records. A generated timestamp is not a promise that every underlying measurement is current.

Use server-side requests for integrations; these examples make no cross-origin browser access promise. Cache responses and inspect the published timestamps and measurement states. No availability guarantee or new reuse license is implied; see Technology & Rights.

Actions and integration contracts

These are the actions already advertised in agents.json. Reading public files is separate from submitting a request. No action runs from this reference page.

Desk email signup requires the existing anti-forgery token and inbox confirmation. Pending is not subscribed. Authenticated feedback requires the declared Obelisk scope and idempotency key. Existing access rules apply.

  • feedback.submit

    Submit a fixed-vocabulary, anonymous page-usefulness signal. The action is deny-by-default, scope-bound, idempotent, and returns a signed receipt.

    POST https://vaultsparkstudios.com/api/agent-actions/v1

    Obelisk: vaultspark:feedback:write

    Request, consent and response contract
    {
  "auth": {
    "authority": "Obelisk",
    "scope": "vaultspark:feedback:write"
  },
  "idempotency": {
    "header": "Idempotency-Key",
    "required": true,
    "retentionSeconds": 86400
  },
  "receipt": {
    "format": "application/json",
    "signature": "HMAC-SHA256"
  }
}

  • site.search

    Open the site search for a query. Returns an HTML results page drawn from the public search index; the same target is declared as the WebSite SearchAction in the entity graph.

    GET https://vaultsparkstudios.com/search/?q={query}

    Public; no account token required

    Request, consent and response contract
    {
  "parameters": {
    "q": {
      "type": "string",
      "required": true,
      "description": "Search terms."
    }
  },
  "auth": "none"
}

  • Ask the Vault

    One grounded, cited answer. Retrieval runs over the canonical facts source, llms-full.txt and The Desk feed; when no passage supports an answer it returns noAnswer with suggested pages instead of guessing. Cite the returned URLs, not the endpoint.

    POST https://fjnpzjjyhnpmunfoycrp.supabase.co/functions/v1/semantic-search

    Public; no account token required

    Request, consent and response contract
    {
  "contentType": "application/json",
  "body": {
    "query": {
      "type": "string",
      "required": true,
      "minLength": 3,
      "maxLength": 200,
      "description": "A plain-language question about VaultSpark Studios, its projects or The Desk."
    }
  },
  "auth": "none",
  "limits": {
    "cost": "Fails closed under a shared daily spend cap; when it trips the endpoint answers 503 with Retry-After instead of a model reply.",
    "cache": "Identical questions are answered from a 24-hour cache keyed to the corpus version, at no model cost."
  },
  "response": {
    "format": "application/json",
    "fields": [
      "answer (prose with [n] markers)",
      "citations [{ n, title, url }]",
      "noAnswer",
      "suggestions [{ title, url }]",
      "corpusVersion"
    ]
  },
  "grounding": "https://vaultsparkstudios.com/api/public-intelligence.json"
}

  • Subscribe to The Desk Dispatch

    Humans and agents may request an invitation for an inbox they control or are authorized to manage. GET /_csrf, POST JSON email with X-CSRF-Token, then follow the signed confirmation link from that inbox. Pending is not subscribed.

    POST https://vaultsparkstudios.com/desk/dispatch/subscribe

    Public; no account token required

    Request, consent and response contract
    {
  "contentType": "application/json",
  "body": {
    "email": {
      "type": "string",
      "required": true,
      "description": "The subscriber’s own email address."
    }
  },
  "auth": "none",
  "humanVerification": {
    "required": false,
    "method": "Email double opt-in for humans and agents."
  },
  "limits": {
    "rate": "Three submissions per hour per network address; one invitation per recipient per day; bounded daily send budget."
  },
  "contract": "https://vaultsparkstudios.com/api/desk-dispatch-contract.json",
  "csrf": {
    "tokenUrl": "https://vaultsparkstudios.com/_csrf",
    "header": "X-CSRF-Token"
  },
  "humanHandoff": "https://vaultsparkstudios.com/news/"
}
