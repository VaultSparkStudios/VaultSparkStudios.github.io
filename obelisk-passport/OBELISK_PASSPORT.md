# Obelisk Passport — VaultSpark Studios

Generated by Obelisk Wave 59. This wires **VaultSpark Studios** into the one shared
Obelisk identity service. All accounts, passkeys, and sessions live at the IdP
(**https://obeliskgate.com**) — this project stores **no credentials and no secret**.

- **Type:** marketing-site  ·  **Archetype:** static-html  ·  **Tier:** T4
- **Theme:** marketing-site (bold)
- **Return/callback:** https://vaultspark.studio/auth/callback

## Wiring (the only manual steps)

1. Deploy login.html and callback.html alongside index.html.
2. Link "Sign in" to /login.html. On return the IdP hits /auth/callback — point your host's /auth/callback to callback.html (or a Worker that calls https://obeliskgate.com/auth/verify-session).

## How it works

1. User clicks **Sign in** → redirected to https://obeliskgate.com/auth.
2. They authenticate (passkey-first, no password) at the IdP.
3. IdP redirects back to https://vaultspark.studio/auth/callback?obelisk_session=<token>.
4. This project verifies the token **server-to-server** at https://obeliskgate.com/auth/verify-session
   and receives only `{ ok, identityId }`. No secret ever touches this repo.

## Environment

```
OBELISK_IDP=https://obeliskgate.com

```

Nothing else. The IdP holds the signing secret and the identity database.
